# gh-browse-or-reload


To successfully tie your command line to your web browser tabs, we have provided a clean Python CLI script that intercepts gh browse, combined with a Chrome/Edge Extension bridge package to handle tab detection and reloads.

------------------------------

## File Architecture

* 
* gh-browse-or-reload.py: The main executable Python CLI script. It queries gh browse --no-browser to get the target destination, attempts a fast automation reload on your running browser window, and cleanly drops back to standard gh browse if the tab isn't open yet.
* manifest.json & background.js: A lightweight Chrome Extension bundle. Web browsers block external shell scripts from probing tab states directly without explicit permission. Loading this lightweight extension grants the script access to view and reload existing GitHub URLs.
* 

------------------------------


## Step-by-Step Installation## 1. Load the Browser Bridge Extension

   1. Open your browser and navigate to chrome://extensions/ (or edge://extensions/).
   2. Toggle the Developer mode switch in the top-right corner.
   3. Click Load unpacked in the top-left corner.
   4. Select the directory containing your generated manifest.json and background.js files.
   5. Copy the Extension ID generated by the browser interface (a long string of random lowercase letters).

## 2. Configure and Deploy the Python CLI

   1. Open gh-browse-or-reload.py and replace "YOUR_EXTENSION_ID_HERE" with the ID you copied from your browser.
   2. Make the script globally executable and move it to your system PATH:
   
   chmod +x gh-browse-or-reload.py
   mv gh-browse-or-reload.py /usr/local/bin/gh-browse-or-reload
   
   
## 3. (Optional) Create a Shell Alias
For an optimal workflow, add an alias to your shell profile (~/.zshrc or ~/.bashrc) so that running gh browse runs your script automatically:

alias gh-browse="gh-browse-or-reload"

------------------------------

## Usage Examples
The tool accepts all flags native to the official [GitHub CLI Browse Command](https://cli.github.com/manual/gh_browse).

* 
* Open or refresh current repository:

gh-browse-or-reload

* Target specific sub-panels like issues or pull requests:

gh-browse-or-reload --issues
gh-browse-or-reload --settings

* Target a completely different repository path:

gh-browse-or-reload cli/cli

*
